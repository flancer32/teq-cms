# Publication Code Map

- Path: `ctx/docs/code/publication.md`
- Changed: `20260930`

This map refines the required [publication contract](../architecture/publication.md).

- `src/Back/Config.mjs` projects family and agent-message settings from `TEQ_CMS`. It rejects prefixes beginning with a maintained tmpl locale. Publication source selection consumes tmpl's existing locale configuration; a nonempty family list is legacy compatibility mode.
- `src/Back/Publication/Source.mjs` validates locale, route, path containment, YAML front matter, and Markdown rendering. Exact locale reads and neutral resource selection share these eligibility checks. `readHtml()` preserves authored unlocalized priority for neutral HTML and never substitutes another localized language. Site mode supports the empty-string unlocalized source locale; `hasRoute()` detects authored invalid routes before delivery fallback.
- `src/Back/Publication/Catalog.mjs` enumerates the policy-selected source corpus in stable route order for host indexes and discovery. Its `getPresentation()` loads a nonempty family template through tmpl; `listHtml()` filters sources with that same check for HTTP links and discovery. Locale variants retain their source identity; neutral discovery identifies each available publication resource once.
- `src/Back/Publication/Representation.mjs` selects `.md`/`.html` before headers, compares supported `Accept` weights, classifies ambiguous requests by `User-Agent`, and defaults to HTML. It does not select a source or define access control.
- `src/Back/Publication/Handler.mjs` parses one supported HTTP representation suffix before strict logical-route validation. It checks authored route presence before ordinary delivery and resolves root index aliases through Routing. It produces raw Markdown or HTML from the selected source, resolving HTML language through `Helper/Web.extractLocale()` (URL, Accept-Language, default) and `Source.readHtml()`. Neutral Markdown retains its stable source preference. Neutral HTML checks unlocalized content first, then the exact selected locale. Extensionless requests send `Vary: Accept, User-Agent` with `Accept-Language` for neutral addresses; neutral `.html` sends `Vary: Accept-Language`; explicit suffixes override headers. HTML canonical and locale links stay extensionless; Markdown alternate links use guaranteed `.md` addresses. It is registered at PROCESS stage before template and static handlers and renders the family presentation target through `Fl32_Tmpl_Back_Service_Render$` with the architecture-defined data and links.
- `src/Back/Discovery/Generator.mjs` builds and writes static discovery files through `cms:generate`, using the same source eligibility and selection rules as HTTP representations.
- `src/Back/Cli/Plugin.mjs` registers publication/static exclusions, ordinary templates/static handlers, the enabled agent handler, and terminal `Web/Handler/NotFound`. Explicit publication/static failures delegate to `Web/Error/Respond`; `Web/Error/Policy` is the host-replaceable template-name contract. See [error responses](../architecture/errors.md).
- `src/Back/Publication/Policy.mjs` is the replaceable host contract for mode, static prefixes, and route presentation selection. `Routing.mjs` validates policy and defines shared source exclusions and canonical paths.
- `src/Back/Web/Handler/StaticRoute.mjs` delegates static-only URLs to the standard static handler before Markdown/template processing and terminates missing files with 404.
- `src/Back/Web/Handler/AgentMessage.mjs` receives optional GET contact messages; `src/Back/Agent/Inbox.mjs` saves them outside public `web/`.

The public DI contracts for metadata consumers are `Fl32_Cms_Back_Publication_Source$` and `Fl32_Cms_Back_Publication_Catalog$`.
