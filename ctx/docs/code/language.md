# Project Language Policy

- Path: `ctx/docs/code/language.md`
- Changed: `20260930`

- All project documentation, specifications, and organizational texts are written in English.
- Project-owned user-interface texts, labels, and explanatory messages are written in English. Authored publication content and localized host presentation follow the product locale model; this development language policy does not select the site's default locale.
- Source comments, logs, error messages, and service strings are written in English.
- Any deviation from this policy is an error to be corrected.
